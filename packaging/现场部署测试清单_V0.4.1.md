# 江西片区智能交接班 V0.4.1 现场部署与反馈清单

这份清单用于第一次在单位局域网部署。建议按顺序逐项测试，并把控制器生成的部署测试 JSON、失败截图和本清单中的反馈信息发回，以便继续适配。

## 一、最终目录怎么放

常开 Windows 主机负责运行；`\\192.168.14.52\江西片区检修中心` 负责保存发布文件、网页入口和备份副本。

```text
常开 Windows 主机（真实运行）
├─ D:\江西片区智能交接班服务器\V0.4.1     EXE 与 _internal
├─ C:\ProgramData\JXHandoverServer         设置、加密密钥、控制状态和运行日志
└─ D:\JXHandoverData                        正式数据，可在控制器中改为其他本地固定盘
   ├─ data\handover.db                       唯一正式数据库
   ├─ imports                                导入原件
   ├─ generated                              生成 Word 与历史版本
   ├─ snapshots\full_backups                 完整备份 ZIP 与清单
   ├─ snapshots\restore                      恢复任务与结果
   └─ .r\b-*                                  恢复时保留的启动前回滚目录

共享盘（不运行 EXE、不直接打开活数据库）
└─ \\192.168.14.52\江西片区检修中心\交接班系统
   ├─ 发布包
   ├─ 江西片区智能交接班系统.url
   └─ 服务器备份
```

正式数据目录可以自定义为服务器本机 `C:`、`D:` 等固定磁盘。控制器会阻止以下位置承载活数据库：

- `\\192.168.14.52\...` 等 UNC 共享路径；
- 映射为 `Z:` 等盘符的网络共享；
- U 盘、光盘或不可稳定写入的目录；
- OneDrive、坚果云等正在同步的个人云盘目录。

共享盘仍然是灾备的一部分：程序先在本机生成含数据库、导入原件和历史 Word 的完整 ZIP，通过 ZIP、逐文件 SHA256 和 SQLite 完整性检查后，才复制到 NAS。NAS 暂时断开时，网页业务和本地备份仍可继续，失败任务会等待补同步。

## 二、服务器 IP 怎么填

控制器中的“局域网 IP 或主机名”填写的是**运行 `交接班服务器.exe` 的常开 Windows 主机地址**，不是 NAS 地址 `192.168.14.52`，也不是路由器网关。

推荐让网络管理员在 DHCP 服务器上为该主机做地址保留。若单位要求手工静态 IP，应由网络管理员提供 IP、子网掩码、网关和 DNS，避免自行挑选造成冲突。

1. 在服务器上打开 PowerShell，运行：

   ```powershell
   ipconfig
   ```

2. 找到实际连接单位内网的网卡，记录其 IPv4，例如 `192.168.14.60`。不要使用：

   - `127.0.0.1`；
   - `169.254.x.x`；
   - 虚拟机、VPN 或已断开网卡的地址；
   - NAS 的 `192.168.14.52`，除非服务真的运行在该设备上。

3. 在控制器点击“重新检测”，选择同一地址；点击“测试当前配置”。
4. 启动服务器后，在另一台电脑运行：

   ```powershell
   Test-NetConnection 192.168.14.60 -Port 8765
   ```

   `TcpTestSucceeded` 应为 `True`。
5. 浏览器打开：

   ```text
   http://192.168.14.60:8765
   ```

如果服务器 IP 会随重启改变，共享盘 `.url` 入口也会失效，因此固定 IP 或稳定的内部 DNS 名称是正式上线条件。

## 三、第一次配置

1. 把 ZIP 从共享盘复制到服务器本地并完整解压，不要直接在 NAS 或 ZIP 内运行。
2. 双击 `服务器控制器.exe`，进入“服务器设置”。
3. 第一次启动前填写：

   - 局域网 IP 或主机名；
   - 正式数据目录，例如 `D:\JXHandoverData`；
   - NAS/云盘备份目录，例如 `\\192.168.14.52\江西片区检修中心\交接班系统\服务器备份`；
   - Qwen API Key；
   - 系统访问口令和管理员姓名。

4. 点击“测试当前配置”。应至少看到：

   - 局域网访问地址通过；
   - 正式数据目录通过；
   - NAS/云盘备份目录通过；
   - 8765 空闲或已由本系统正常运行。

5. 测试报告保存在：

   ```text
   %PROGRAMDATA%\JXHandoverServer\deployment-tests
   ```

6. 点击“保存服务器设置”后启动服务器。

注意：控制器配置测试使用当前登录的管理员账号。启动服务后还必须进入网页“系统管理”，点击“以服务身份测试”；后者才代表 SYSTEM 或服务账号的真实 NAS 权限。
