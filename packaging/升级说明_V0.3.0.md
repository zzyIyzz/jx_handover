# 江西片区智能交接班 V0.3.0 升级说明

## 最省事的升级方法

1. 把完整 ZIP 解压到一个新的文件夹，不要覆盖旧版程序目录。
2. 双击 `交接班系统.exe`。
3. 控制器会自动启动系统，并按你的设置打开浏览器。
4. 首次升级时，程序会查找旧版 `runtime`；如果没有自动找到，点击“选择旧版数据目录”。

数据、导入原件、历史 Word、快照和日志统一保存在：

`%LOCALAPPDATA%\JXHandover`

以后替换或删除程序目录不会覆盖上述数据。迁移旧数据库前，系统会先把原数据库备份到 `snapshots`。

## 本版重点变化

- 固定只在本机 `http://127.0.0.1:8765` 运行。
- 新增无黑色命令行窗口的控制器，可启动、打开、停止、重启、查看状态、打开数据和日志目录。
- 网页严格保留一至六章，第三、第四、第五章独立编辑；6.3 年度工作追加在 6.2 后。
- 人员选择和 Word 只显示姓名，岗位信息仍在系统内部保留。
- Excel 导入先预览后确认，支持第三、第四、第五章，重复提交不会重复写入。
- Word 改用原始交接班记录版式母版，保留列宽、表头、颜色和分页规则。

## 端口冲突

如果 8765 已由本系统占用，控制器会提示“系统已运行”并打开网页；如果由其他程序占用，控制器会显示处理提示，但不会强制结束其他程序。

## 完整性校验

下载后可对 ZIP 执行：

```powershell
Get-FileHash .\江西片区智能交接班_V0.3.0_win-x64.zip -Algorithm SHA256
```

结果应与同名 `.sha256` 文件一致。
