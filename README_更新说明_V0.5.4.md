# V0.5.4 合并更新说明

截至 2026 年 9 月 19 日，`release/v0.5.4` 已合并登录体验、月度例会材料和年度定期工作记忆，同时保留 Excel 兼容、Qwen AI 恢复、数据恢复、账号密码连续性及固定数据目录能力。

## 功能更新

- 所有密码输入框实时提示 Caps Lock 状态。
- 登录页新增忘记密码弹窗，指引联系周智源核实后重置密码。
- 新增“例会材料”页面，仅汇总已发布班次的重点工作、交接工作和定期工作。
- 月度例会材料支持 Excel 导出，包含状态、优先级、场站、责任人和进展。
- 新增全年年度定期工作台账。
- 交接班 6.3 年度定期工作显示本年度之前最近一次记录；当前年度记录不会作为往年记忆。

## 保留的生产约束

- 管理员必须且只能为周智源：`JX_ADMIN_NAMES=周智源`、`JX_DEFAULT_ADMIN_NAMES=周智源`。
- systemd 与 Docker 正式数据均位于 `/data/jx-handover/data`。默认允许使用系统盘；以后挂载独立 ESSD 到 `/data` 时无需改变应用数据路径。
- 账号、Argon2id 密码哈希、交接班记录、Word、导入原件、备份和 root-only 配置副本均受升级脚本保护。
- 数据恢复失败、中断或回滚失败时保持关闭并保留恢复现场。

## 云服务器升级

将完整的 `升级脚本_V0.5.4` 文件夹上传服务器后执行；当前未购买独立云盘时会使用系统盘上的 `/data`：

```bash
sudo bash one-click-v0.5.4.sh
```

脚本不会执行磁盘格式化或挂载操作；它负责数据复制校验、root 工具安装、代码更新、数据库迁移、账号密码核对和服务健康检查。
