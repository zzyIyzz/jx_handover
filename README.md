# 江西片区智能交接班系统 · 使用说明

第一版（最小闭环）：修水眉毛山 / 万安韶口 / 宁都真君堂三场站共用。
核心原则：**数据库是唯一事实源，Web 是唯一编辑入口，日期/超期/颜色规则全部由程序计算，AI 无发布权限。**

## 一、启动

双击或在 PowerShell 中执行：

```powershell
cd c:\Users\zzzaa\Desktop\交接班工作\jx-handover
.\start.ps1
```

启动后浏览器访问 **http://127.0.0.1:8080** （前端由后端直接托管，无需另开前端）。

首次运行自动初始化数据库并写入三个种子场站。
如需演示数据（修水 2026.8.14~8.23 真实班次内容）：

```powershell
.\.venv\Scripts\python.exe backend\scripts\seed_demo.py
```

## 二、导入真实数据

在「交接班班次」页之前，先通过 API 导入（第一版导入入口为接口，后续加页面）：

1. **班会记录**（腾讯文档导出 XLSX）：

   ```
   POST /api/imports/xlsx   （multipart：file，可选 default_year、station_code）
   ```

   程序自动完成：日期清洗（8.20 / 8月22日 → 2026-08-20）、场站识别（场站列→Sheet名→别名→关键词）、SHA256 去重。

2. **月度/季度定期工作计划**：

   ```
   POST /api/imports/monthly-plan   （multipart：file、plan_month，可选 category=quarterly、station_code）
   ```

## 三、新建班次并复核

1. 首页点击「新建交接班」→ 填写交接开始/截止日期、交接班时间、选择场站 → 创建。
   程序自动完成：窗口内记录硬过滤 → 规则+AI 合并事项 → 生成全班快照与定期工作。
2. 进入复核页，逐张卡片核对：
   - 点击卡片打开编辑抽屉，可修改标题/状态/优先级/进展/责任人/日期，底部可查**原始证据**（来源班会记录）。
   - 确认无误点「确认无误」；需要修改先「保存修改」再确认。
   - 全部确认前**禁止生成正式 Word**（系统硬校验）。
3. 基本信息卡片填写值班负责人、当班值班员；设备变更卡片可追加本班设备变更。

## 四、生成正式 Word

复核全部确认后，点击「生成正式 Word」：

- 六节结构与现有修水格式一致；颜色由程序自动计算：
  紧急=红、重点=黄、已完成=绿、期限内未完成=白、**超期未完成=红**。
- 生成后自动校验 DOCX 完整性并登记版本快照（V001、V002……），
  输出到 `runtime\generated\{场站码}\{年月}\发布历史` 与 `当前版`。
- 页面版本记录表可直接下载；配置 `.env` 中 `CLOUD_PUBLISH_DIR` 后还会同步到云盘目录。

## 五、接入真实 Qwen AI（可选）

默认 `AI_MODE=mock`（本地确定性模拟，无需网络）。接入真实模型：
编辑项目根目录 `.env`：

```
AI_MODE=qwen
QWEN_BASE_URL=<OpenAI兼容地址>
QWEN_MODEL=<模型名>
QWEN_API_KEY=<密钥>
```

改完重启即可。AI 只做合并判断与文本整理，所有结果带来源硬校验，且永远没有发布权限。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 8080 端口被占用 | 修改 `.env` 的 `APP_PORT` 并同步修改 `start.ps1` 的 `--port` |
| 提示“版本冲突” | 该事项刚被保存过，刷新后重新编辑 |
| 生成 Word 报“待复核” | 仍有未确认事项，逐条确认或点「一键全部确认」 |
| 重置演示数据 | 删除 `runtime\data\handover.db` 后重新执行 start.ps1 + seed_demo.py |
