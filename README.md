# 江西片区智能交接班系统

当前版本：**V0.2.0 易用版**

面向修水眉毛山、万安韶口、宁都真君堂等场站的本地交接班工作台。系统把班会记录导入、事项整理、人工复核、定期工作确认和 Word 发布放在同一个浏览器页面内完成。

核心原则：**数据库是唯一事实源，Web 是唯一编辑入口，日期/超期/颜色规则全部由程序计算，AI 无发布权限。**

## 一、启动

双击 `start.ps1`，或在 PowerShell 中执行：

```powershell
cd C:\Users\zzzaa\Desktop\交接班工作\jx-handover
.\start.ps1
```

启动后访问 <http://127.0.0.1:8080>。前端已由后端直接托管，不需要再打开第二个命令窗口。

首次运行会自动初始化数据库并写入三个种子场站及人员字典。

## 二、最省事的使用流程

### 1. 导入班会记录

在工作台点击「导入数据」：

1. 选择「班会记录」。
2. 把腾讯文档或 Excel 导出的 `.xlsx` 文件拖入窗口。
3. 确认年份；场站通常保持「自动识别」。
4. 点击「开始导入」。

系统自动清洗日期、识别场站、保存原始来源并按内容去重。同一文件可以放心重复导入，已有内容会被跳过。日期无法识别时，页面会直接提示异常行数。

月度、季度、年度的实际计划也可以在同一窗口切换到「定期工作计划」后导入。

### 2. 新建交接班

点击「新建交接班」。系统会自动：

- 预填最近 10 天；也可一键切换最近 7 天。
- 把交接班日期同步为截止日期。
- 沿用上一次选择的场站；首次使用默认全选。

确认摘要后点击「创建并进入复核」。程序会完成时间窗硬过滤、规则与 AI 合并、全班快照生成，以及内置定期工作匹配。

### 3. 快速复核

复核页顶部会显示当前场站的完成比例、紧急/重点数量、定期工作超期数量和最新 Word 版本。

- 正确事项：在卡片右侧直接点「确认无误」。
- 多条均正确：使用「一键确认全部」，系统以一次事务完成。
- 需要修改：点开卡片，修改后使用「保存并确认，下一条」。系统会自动打开下一条待复核事项。
- 键盘操作：抽屉打开时按 `Ctrl + Enter`，等同于「保存并确认」。
- 人员信息：选择后自动保存，不再需要额外点保存。
- 定期工作：勾选「已完成」后自动保存；超期只按交接班日期计算。

所有事项确认完成前，系统会硬性禁止生成正式 Word。

### 4. 生成并下载 Word

复核完成后，在页面底部点击「生成并下载 Word」。系统会：

1. 按正式模板生成文档。
2. 自动校验 DOCX 完整性。
3. 登记 `V001`、`V002` 等历史版本。
4. 更新「当前版」。
5. 自动开始浏览器下载。

本地文件位于：

```text
runtime\generated\{场站码}\{年月}\发布历史
runtime\generated\{场站码}\{年月}\当前版
```

如在 `.env` 中配置 `CLOUD_PUBLISH_DIR`，正式版本还会同步到指定云盘目录。

## 三、业务规则

- 专业记录只允许进入所选闭区间 `[开始日期, 截止日期]`。
- 紧急事项为红色，重点事项为黄色，普通事项为白色。
- 定期工作已完成为绿色；未完成且截止日早于交接班日才算超期并标红。
- AI 只负责合并判断和文本整理，所有结果必须保留原始来源。
- 待复核事项不能进入正式 Word。
- 每次正式生成都产生不可覆盖的独立版本快照。

## 四、接入真实 Qwen AI（可选）

默认 `AI_MODE=mock`，不调用外部网络。需要接入真实模型时，编辑项目根目录 `.env`：

```dotenv
AI_MODE=qwen
QWEN_BASE_URL=<OpenAI 兼容地址>
QWEN_MODEL=<模型名>
QWEN_API_KEY=<密钥>
```

重启系统后生效。API 密钥只保存在本机 `.env`，该文件不会提交到 Git。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 页面打不开 | 确认 `start.ps1` 窗口仍在运行，并访问 `http://127.0.0.1:8080` |
| 8080 端口被占用 | 修改 `.env` 的 `APP_PORT`，并同步修改 `start.ps1` 的 `--port` |
| 导入提示日期未识别 | 确认导入窗口中的年份正确，并把原表日期改为 `8.20`、`8月20日` 或完整日期 |
| 导入同一文件两次 | 无需处理，系统会自动跳过重复记录 |
| 提示版本冲突 | 内容刚被其他页面修改；刷新后重新编辑即可 |
| 不能生成 Word | 仍有专业事项待复核，请在「待复核」筛选中完成确认 |
| Word 没同步到云盘 | 检查 `.env` 的 `CLOUD_PUBLISH_DIR` 是否为实际同步目录 |

版本变化见 [CHANGELOG.md](CHANGELOG.md)，后续升级优先级见 [ROADMAP.md](ROADMAP.md)。
