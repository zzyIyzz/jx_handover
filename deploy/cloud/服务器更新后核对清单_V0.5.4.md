# 服务器更新后核对清单（V0.5.4）

完成 [升级与验收](升级与验收_V0.5.4.md) 后，在现有 systemd 项目目录执行：

```bash
cd /www/wwwroot/jx_handover
.venv/bin/python backend/scripts/data_location.py
.venv/bin/python backend/scripts/manage_admin.py --list
curl -fsS http://127.0.0.1:8765/api/health
```

- 版本为 `0.5.4`，`admin_configured` 为 `true`。
- 数据根与升级前相同，人员与交接班历史数量合理。
- 默认管理员为周智源；显式配置其他名单时以配置为准，不要未经确认回收其他权限。
- 管理页“测试 AI 连接”成功且模式为 Qwen；缺少真实 Key 时运行配套 `restore-ai.sh`。只看到模型名称不能证明已启用。
- 原先失败的 XLSX 可以导入预览；核对日期、场站、内容和责任人后再确认导入。

异常时保留备份路径并运行 `journalctl -u jx-handover -n 100 --no-pager`。不要把旧数据库直接覆盖回正在运行的服务。
