# V0.5.0 云端部署优化计划与发布门槛

## 目标

把当前“Windows 常开主机 + 局域网”的单实例系统升级为可在阿里云 ECS 上长期运行、由宝塔管理 HTTPS、使用 ECS 本地数据盘和 OSS 异地备份的私有云版本，同时不牺牲原有六章、Excel 导入、Qwen3.8-Flash、Word 历史版本和数据可恢复性。

## 阶段 A：私有云现场测试版（当前实现）

- Docker 多阶段构建：Node 构建前端，Python 运行后端。
- Compose 固定单实例、单 worker、非 root、只读根文件系统。
- Docker 只发布内部 `127.0.0.1:8765`；宝塔 Nginx 在公网 HTTPS 1215 监听。
- 宝塔 Nginx 负责域名、HTTPS、反向代理和固定 IP/VPN 白名单。
- 云端配置失败关闭：HTTPS、可信域名、Secure Cookie、长口令、长会话密钥、管理员与私有访问声明缺一不可。
- 登录失败限流、跨站写请求拦截、HSTS、CSP 和常用浏览器安全头。
- `/api/health` 云端只返回最小健康信息，敏感路径只在管理员诊断接口显示。
- ECS 本地 ESSD 保留唯一正式 SQLite；Docker 镜像升级不覆盖数据。
- 完整备份通过 ECS RAM 角色上传私有 OSS，不保存长期 AccessKey。
- 支持 OSS 下载、全量校验、重启前恢复。
- 修复 Windows 备份恢复到 Linux 后的历史 Word 路径重写。

阶段 A 的发布门槛：

1. 本地后端回归测试与前端生产构建通过。
2. Compose 配置和全部 Bash 脚本静态校验通过。
3. 在真实阿里云 ECS 构建镜像并通过健康检查。
4. 固定 IP/VPN 白名单内外测试通过。
5. 真实 Excel、六章 Word、多人冲突、Qwen 回退测试通过。
6. Windows 完整备份迁移到 Linux 并恢复通过。
7. OSS 上传、下载、校验、恢复演练通过。
8. ECS 重启和容器重建后数据仍完整。

未通过现场门槛前：不合并 `main`、不创建 `v0.5.0` 正式标签、不声明云端生产发布完成。

## 阶段 B：任意公网网络访问前的身份升级

如果人员需要从家庭网、手机网等任意网络直接访问，必须先完成：

- 每人独立账号与独立密码，不再用一个共享访问口令代表身份。
- Argon2id/bcrypt 密码哈希、首次登录改密、管理员重置、账号禁用。
- 登录名与操作审计身份强绑定，不能登录后再任意选择他人姓名。
- 可选 TOTP/企业身份源 MFA。
- 恢复码、会话撤销、设备退出、短会话和敏感操作重新认证。
- 未认证接口不再返回完整人员名单。
- 持久化登录限流/锁定，避免重启绕过内存限流。
- CSRF Token、来源校验、安全响应头与反向代理真实 IP 信任链复核。
- 第三方渗透/弱口令/越权/文件上传安全测试。

在阶段 B 完成前，Nginx 白名单或 VPN 是强制安全边界，不是可选优化。

## 阶段 C：容量和高可用升级（有数据再做）

当前小团队单实例不需要为了“看起来像云原生”过早增加复杂度。达到下列信号后再评估 PostgreSQL 和多实例：

- SQLite 写锁等待在真实使用中持续出现；
- 同时活跃编辑人数明显增长；
- 单机维护窗口不可接受；
- 需要跨可用区自动故障转移；
- 数据量和备份窗口超过单机方案的可控范围。

对应升级方向：

- PostgreSQL 托管版 RDS，数据库迁移与回滚演练。
- 生成 Word/导入原件迁移到私有 OSS，对象键写入数据库。
- 后端无状态化、多个实例、SLB 健康检查。
- 分布式任务队列处理 AI、Word 和大文件导入。
- 可观测性：结构化日志、错误追踪、请求耗时、队列积压和业务备份新鲜度。

## 人性化操作优化队列

现场测试后按实际痛点排序，而不是一次堆满功能：

1. 云端管理页直接显示“最近 OSS 成功时间、失败原因、证书到期、磁盘预警”。
2. 管理员页面提供“一键复制脱敏诊断”，自动排除 Key、口令和业务正文。
3. 导入大文件显示分阶段进度：上传、解析、AI 整理、人工确认、入库。
4. 多人同时编辑时显示“谁正在查看/编辑”，冲突前提前提醒。
5. 自动保存增加离线草稿和恢复提示，网络恢复后先比较版本再提交。
6. 移动端优化常用确认、交接、查看 Word，复杂编辑仍以电脑端为主。
7. 备份恢复向导明确区分“下载到本地”“安排恢复”“重启生效”。
8. 一键生成现场反馈包，只含版本、健康、匿名错误编号和脱敏日志。

## 运维优化队列

- 阿里云云监控：CPU、内存、磁盘、实例状态、EIP 流量。
- 证书到期提醒与自动续期失败告警。
- 每日完整备份新鲜度、OSS 同步失败和恢复演练逾期告警。
- Docker 镜像版本、Git 提交、配置摘要（不含密钥）写入管理员诊断。
- 构建依赖锁定、镜像漏洞扫描、SBOM、镜像签名。
- 自动化升级前备份与升级后冒烟，失败时保留旧镜像，不自动删除数据。
